BNL — BEN CALDWELL
1. Sao chép assets/js/ben-data.js vào D:\BNL\assets\js.
2. Trong index.html HIỆN TẠI, thêm dòng sau ngay trước script app.js (chỉ thêm một lần):
<script src="assets/js/ben-data.js?v=20261122-ben1"></script>
Bản index.html kèm theo được ghép từ bản Community 16/11; nếu đã sửa index sau đó, chỉ thêm dòng trên, không ghi đè.
3. Giữ nguyên ảnh gốc tại assets/images/ben/profile.jpg và 1.jpg đến 7.jpg. Nhạc assets/music/ben.mp3 nếu đã có.
4. VS Code Terminal (D:\BNL):
 git add index.html assets/js/ben-data.js assets/images/ben
 git status -sb
 git diff --cached --stat
 Nếu đã có nhạc: git add assets/music/ben.mp3
 git commit -m "Them Benjamin Ben Caldwell"
 git push
5. Kiểm tra GitHub Pages. Không cần chạy thêm SQL. Link GGAI trống, đăng bằng Admin khi có.
Không có ảnh/nhạc thay thế trong ZIP; không công khai system prompt.
